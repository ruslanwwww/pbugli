# Уголь — таймеры кальянов (Par BAR)

Веб-приложение для персонала: 13 столов и 8 кабин, у каждой точки свой независимый
таймер замены угля. Работает в браузере телефона, ставится на домашний экран, работает офлайн.

## Как пользоваться

1. Открыть ссылку → нажать **«Включить звук»**. Должен прозвучать короткий сигнал —
   это проверка. Тишина значит, что телефон на беззвучном или убавлена громкость.
2. Отдал кальян на стол → нажать **«Готово»** на карточке этого стола. Пошёл отсчёт 20 минут.
3. За 30 секунд до конца карточка становится целиком красной и мигает, снизу появляется
   полоса с кнопкой **«Отключить»** — звук глушится, отсчёт продолжается.
   Нажатие на текст полосы прокручивает экран к нужной точке.
   После нуля карточка продолжает мигать и показывает просрочку: `+01:35`.
4. Заменил уголь → **«Заменил»**, таймер стартует заново.
5. **«+5 мин»** — продлить, **«Стоп»** — освободить точку.

Шестерёнка сверху: длительность таймера, за сколько секунд сигнал, выбор сигнала
(гудки / сирена / звонок), проверка звука, сброс всех.

Рядом с шестерёнкой — индикатор **«Звук вкл / выкл»**. Если написано «выкл», звука не будет:
нажми на него, чтобы переспросить разрешение.

## Что важно знать

- Таймеры считаются по часам телефона от момента запуска, а не тиками.
  Приложение можно свернуть, экран может погаснуть, вкладка может быть выгружена —
  при возврате время будет верным, а просроченные точки сразу зазвонят.
- Пока приложение открыто, в фоне крутится беззвучная петля — так система не усыпляет
  звук, и сигнал слышно из свёрнутого состояния.
- iPhone: обязательно добавить на домашний экран (Поделиться → «На экран "Домой"»)
  и держать приложение открытым. Полностью закрытое приложение iOS звонить не даст —
  это ограничение системы, не приложения.
- Android: работает и в свёрнутом виде; при выданном разрешении дублирует уведомлением
  и вибрацией.

## Публикация на GitHub Pages

```bash
git init
git add .
git commit -m "Таймеры угля Par BAR"
git branch -M main
git remote add origin https://github.com/USERNAME/hookah-timer.git
git push -u origin main
```

Затем: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
Через минуту ссылка будет вида `https://USERNAME.github.io/hookah-timer/`.
